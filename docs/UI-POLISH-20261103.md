# Owner UI polish — 3 November 2026

Status: deployed to production at https://widyafa.xyz/ on 3 November 2026, release `2f9313942a50d36727faca5baa964404bf176a50`. The original SiPeKA sidebar, navigation and login layout remain in use.

## Changes

- Payroll has a page header, three preparation steps, separate template/import panels, and a full-width draft/history register.
- Payroll now separates Input Slip Gaji (templates, upload, Widya review) and Riwayat Slip (drafts, publication, downloads, email) into keyboard-accessible tabs. Switching preserves the live upload/review; successful draft saving opens history. Shared status messages remain visible in either tab.
- General and laundry template actions are grouped by purpose. Additional earnings and deductions can be expanded in the register.
- Upload, review, draft, publication, download and email consent hooks remain connected to the existing module. API and authentication contracts were not changed.
- Dashboard and login typography, spacing, form controls, neutral surfaces and blue accent are consistent across light/dark modes. Small screens stack panels and keep wide financial tables inside their own horizontal scroll containers.
- The floating Widya control no longer overlaps the top command bar.

The design follows the locally installed unslop skill by Damir Sokolovsky (CC BY 4.0). Attribution is retained in the CSS.
